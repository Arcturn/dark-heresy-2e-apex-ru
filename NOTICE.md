# Сторонние компоненты

В модуль включены только шрифты и новые файлы локализации. Исходные файлы
Dark Heresy 2E [Apex Edition], Babele, libWrapper и текст книги правил
в этот архив не включены.

## Roboto

Источник: https://github.com/google/fonts/tree/main/ofl/roboto

Файл `Roboto[wdth,wght].ttf` преобразован в WOFF2 без сокращения набора глифов.
Лицензия SIL Open Font License 1.1 сохранена в `fonts/OFL-Roboto.txt`.

## Roboto Condensed

Источник: https://github.com/google/fonts/tree/main/ofl/robotocondensed

Файл `RobotoCondensed[wght].ttf` преобразован в WOFF2 без сокращения набора глифов.
Лицензия SIL Open Font License 1.1 сохранена в `fonts/OFL-RobotoCondensed.txt`.

Шрифты получены 4 ноября 2026 года. Авторство и условия распространения шрифтов
определяются приложенными лицензиями. CSS использует локальные имена семейств
`DH2E RU Roboto` и `DH2E RU Roboto Condensed`, чтобы не подменять одноимённые
шрифты других модулей.
