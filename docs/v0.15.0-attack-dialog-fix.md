# Аудит исправления окна атаки — v0.15.0

## Наблюдение пользователя

В окне атаки системного Autogun (автоган) при выбранном русском языке остались три английские строки: `Ballistic Skill` (29), `Standard Attack` (+10), `Short range` (+10). Заголовок и остальные статические надписи переведены.

## Воспроизведение причины

1. Исходный шаблон `templates/apps/dh2e-roll-dialog.hbs` выдаёт строки через `.dh2e-roll-list > .dh2e-roll-m > span`.
2. Версия 0.14.0: `roll-modifiers-ui-adapter.mjs` выбирала `root=x?.[0]??x`.
3. Foundry VTT 14: `renderApplicationV2` получает обычный DOM `HTMLFormElement`; свойство `form[0]` возвращает первый дочерний элемент управления формы, а не сам контейнер.
4. Вызов `applyRollModifiersTranslations(...)` не находил `.dh2e-roll` и возвращал `active:false`, несмотря на наличие точных русских значений словаря.
5. Регрессионный тест v0.15 воспроизводит падение на оригинальном адаптере и проходит после исправления.

## Исправление

Учитывать `root.nodeType` перед проверкой `root[0]`. При передаче DOM-элемента использовать его; при передаче массивоподобной старой обёртки использовать `root[0]`. Это сделано для roll-modifiers, actor-rules, runtime-ui, dialog-ui и chat-breakdown адаптеров. Не затрагиваются сохранённые игровые данные и действия кнопок.

## Верификация

- Три русских подписи из реального скриншота.
- Неизменность чисел 29, +10, +10, ключей `action` и `range`.
- Идемпотентность: повторное отображение не дублирует перевод.
- Сохранена поддержка jQuery-подобной обёртки.
- Пройдено 8 сценариев тестовых скриптов и покрытие словаря: 7 048 / 7 048.

**Ограничение:** реальный рендер Foundry VTT 14 и сторонние моды не проверялись в данной среде.
