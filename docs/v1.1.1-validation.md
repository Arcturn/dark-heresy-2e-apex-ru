# Проверка исправления списков в версии 1.1.1

Исправление подготовлено по двум снимкам экрана пользователя. В окнах «Добавить талант» и «Добавить черту» локализовались заголовки, но названия вариантов оставались английскими.

## Причина и изменение

В системе Apex 0.1.12 кнопки «+» вызывают отдельный `DialogV2.prompt` из `src/sheets/actor-sheet.mjs`. Эти окна не являются листом персонажа или окном развития и не имеют обычного CSS-класса системного приложения. Поэтому прежние обработчики их пропускали.

Новый адаптер проверяет класс DialogV2 и сочетание служебных полей конкретного окна. Название переводится только при совпадении канонического ключа и штатного английского текста. Использованы существующие словари всех 102 талантов и 42 черт. Для талантов переводятся также ранги и штатные варианты специализаций, которые система заново создаёт после смены выбранного таланта.

Данные вариантов, выбранный пункт, `data-value`, `data-spec`, числовые значения и пользовательский ввод не переводятся. Наблюдатель ограничен корнем открытого диалога и отключается при его закрытии. Datalist специализаций черт с каноническим текстовым значением этим исправлением не изменяется.

## Воспроизводимая проверка

```bash
node tools/test-rule-picker-v111.mjs
```

Проверка настоящих DOM-элементов и содержимого, создаваемого исходными обработчиками системы:

```bash
DH2E_RU_JSDOM=/path/to/node_modules/jsdom/lib/api.js \
DH2E_RU_SYSTEM_PATH=/path/to/dark-heresy-2e-apex \
node tools/test-rule-picker-v111.mjs
```

Исходная система сверена с коммитом `b3482f7b6628ad0112e2ace1c7aed9df7a6732de` и использована только для чтения. Проверка включает штатные списки, повторное открытие, смену таланта, сохранение канонической специализации и собственное название. Сохранён и общий набор регрессионных проверок модуля.

Результат: все 25 наборов тестов прошли. Дополнительно прошёл прогон исходных обработчиков в jsdom: 102 таланта, 42 черты, 54 специализации, оба порядка вызова системного render и хука, сохранение FormData, замена корня окна и освобождение наблюдателей.

Это проверка кода и DOM. Живой мир Foundry в данной среде не запускался. После установки 1.1.1 необходимо перезагрузить клиент и открыть диалоги заново.
