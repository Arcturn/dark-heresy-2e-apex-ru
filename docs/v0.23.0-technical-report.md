# Dark Heresy 2E [Apex Edition] — технический отчёт v0.23.0

Дата: 7 ноября 2026. База: модуль русификации v0.22.0, система `dark-heresy-2e-apex` 0.1.10, Foundry VTT 14.

## 1. Итог статического аудита

Сканирование извлечённого исходника системы охватило:

| Исходники | Количество |
|---|---:|
| `.mjs` | 607 |

| Карты переводов Babele | 9 из 9 |
| Записи в картах Babele | 905 |

**Важное различие:** 100% покрытия словаря и наличие девяти карт не означают, что 100% текста во время игры уже на русском. В системе есть программно созданные английские сообщения и шаблоны, которые не проходят через `game.i18n`. Подтвердить их отображение можно только тестом соответствующих экранов в Foundry.

Из 41 очевидного статического английского фрагмента шаблонов HBS:

- 29 покрыты точным словарём `hardcoded-ui` (включая исправленное `Operate`);
- 10 являются *ключами локализации* в атрибутах `data-tooltip`, которые должен разрешать клиент Foundry; это не прямая английская надпись;
- 2 являются примерами английского синтаксиса в полях ручного ввода оружия (`Las, Solid Projectile, Chain…` и `Tearing, Proven (3), Blast (2)`). Они оставлены без замены, чтобы не предлагать пользователю ввод, который движок может не распознать.

В CSS найдено три отображаемых английских псевдотекста `GM mode`, `DoS`, `DoF` — для них в v0.22.0 уже были соответствующие русские переопределения. Прочие последовательности `content: "\\f078"` и подобные — символы/иконки, не слова для перевода.

Исходники и классификации: `docs/v0.23.0-static-audit.json` и `docs/v0.23.0-template-candidates.csv`. Повторная проверка: `python3 tools/audit-v023-static.py <путь к извлечённой оригинальной системе>`.

## 2. Подтверждённые исправления

1. **Характеристики оружия транспорта.** В обработчике v0.22.0 был неверный селектор `.apex-veh-weapon .stats i`. Шаблон оригинала содержит `.dh2e-veh-weapon .stats i` (`templates/actor/parts/apex-main-tab.hbs`). Исправлен селектор, подтверждён перевод шести подписей `Class`, `Rng`, `RoF`, `Dmg`, `Pen`, `Clip`.
2. **Транспортная проверка управления.** Штатный шаблон выводит `Operate {{operate}}`. В ограниченном системном контейнере `.dh2e-veh-tiles .apex-sub` добавлен перевод только текстов формы `Operate <число>` → `Управление <число>`. Число не изменяется; похожие пользовательские строки не затрагиваются.
3. **Номера страниц в талантах и чертах.** Шаблон `templates/actor/parts/identity-tab.hbs` показывает `(p. {{page}})`. Для `.apex-rule-body em` добавлен ограниченный перевод `(p. 125)` → `(стр. 125)`. Номер страницы и содержимое правила не изменяются.
4. **Диагностика.** Добавлен чисто читающий API `inspectOpenSystemUI()` для просмотра оставшихся точных английских штатных надписей в открытых системных окнах. Он не ведёт фонового мониторинга, не отправляет данные, не правит DOM или документ и не анализирует пользовательские заметки. Возвращаемые находки — **кандидаты**, не доказательство полного перевода.

Обновлена метаинформация модуля до v0.23.0. Словарь для встроенных подписей теперь содержит **520** соответствий вместо 519. Все девять Babele-карт сохранены *без изменений* относительно v0.22.0.

## 4. Как проверить в Foundry

1. Сделать копию мира и сохранить предыдущий модуль. Полностью заменить папку модуля, перезапустить сервер и браузер (при необходимости Ctrl+F5).
2. Проверить наличие моста контекстов:

```js
console.log(game.modules.get('dark-heresy-2e-apex-ru')?.api?.viewBridgeStatus?.());
```

После загрузки мира `patched` должен включать `actor`, `advancement`, `roll`; `hud` может появиться после первой отрисовки панели.

3. Открыть лист транспорта с оружием и проверить `Класс`, `Дальн.`, `СКС`, `Урон`, `Проб.`, `Магазин`, а также `Управление <число>`.
4. Открыть на листе аколита вкладку «Способности», развернуть талант/черту со страницей в книге: ожидается `(стр. <номер>)`.
5. Открыть несколько окон (прокачка, проверка, лист NPC, редактор предмета) и вручную вызвать **только чтение** оставшихся известных английских строк:

```js
console.table(game.modules.get('dark-heresy-2e-apex-ru')?.api?.inspectOpenSystemUI?.()?.findings ?? []);
```

6. Сравнить до/после: покупку таланта, XP, проверку атаки, дистанцию, снаряжение и применение психосил. Отдельно проверить появление HUD при выборе токена.

## 5. Что остаётся перед полноценной 1.0.0

Статический анализ показывает лишь обнаруженные шаблоном случаи; программно созданные строки JavaScript и сторонние модули требуют отдельного исследования. Нужно проверить живую Foundry 14, очередность загрузки модулей, частичные перерисовки, CSS-темы и русский поиск. Особенно важны окна, которые существуют только после боевых событий. При обнаружении английской строки необходимо указать класс окна и источник формирования, а не просто делать глобальную подмену текста — иначе рискуют пострадать имена игроков, игровые ключи и парсеры.

**Вердикт:** v0.23.0 готова как технический кандидат для практического тестирования. Называть её полностью проверенной «абсолютной русификацией» до такого теста неправильно.
