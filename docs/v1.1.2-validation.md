# Проверка исправления кнопок защиты 1.1.2

Сообщение пользователя: кнопка уклонения в карточке попадания остаётся английской; проверить парирование.

## Причина

`src/combat/dh2e-defence.mjs` строит подпись из `option.label` и `option.target`, сохранённых в флаге сообщения. Здесь нет повторного вызова локализации. Аналогичный путь есть в `dh2e-responses.mjs` для оглушения и захвата. Кроме того, панель с кнопками создаётся обработчиком `renderChatMessageHTML`, который может выполняться позже обработчика модуля перевода.

## Исправление

Адаптер сопоставляет кнопку с конкретной записью `dh2eDefence` или `dh2eResponses` по идентификатору строки и ключу защиты. Переводится только точная штатная подпись вместе с исходным процентом. После синхронных обработчиков рендера выполняется повторная проверка, чтобы охватить поздно добавленную панель.

Обработаны уклонение, парирование, Сила воли, Предчувствие и стандартные кнопки принятия попадания/сопротивления. Предчувствие переведено также в строке результата самой проверки. Имена целей и пользовательские подписи сохраняются, включая совпадение имени или текста травмы с названием проверки. Значения процентов, DOM-узлы кнопок, их атрибуты, обработчики событий и сохранённые флаги не меняются.

## Проверка

```bash
node tools/test-defence-chat-v112.mjs
```

Расширенная проверка на DOM, созданном исходными функциями системы:

```bash
DH2E_RU_JSDOM=/path/to/node_modules/jsdom/lib/api.js \
DH2E_RU_SYSTEM_PATH=/path/to/dark-heresy-2e-apex \
node tools/test-defence-chat-v112.mjs
```

Исходная система — Apex 0.1.12, коммит `b3482f7b6628ad0112e2ace1c7aed9df7a6732de`; использована только для чтения. Проверяются оба порядка вызова обработчиков, обычная атака и карточка ответного действия, сохранность чисел и параметров нажатия, повторная отрисовка и отсутствие перевода пользовательского чата.

Пройдены 26 наборов `tools/test-*.mjs`, дополнительная проверка на DOM с исходными обработчиками системы и интеграционная проверка общего входа модуля. Для карточек защиты проверены исходные запросы к ведущему при нажатии, блокировка недоступных кнопок, оба порядка регистрации обработчиков, повторная отрисовка и отключение адаптера.

Живой мир Foundry в этой среде не запускался. После обновления нужно перезагрузить клиент. Существующие сообщения не мигрируют: перевод применяется при их отображении.
